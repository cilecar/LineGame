# LineGame

Фронтенд каталога игр: главная с каруселями, жанры, страница игры со скриншотами
и описанием.

> Учебный проект. Торрент-файлы в репозиторий не входят.

## Стек

Vue 3 · Vue Router · Vite · Tailwind CSS · Splide · Font Awesome

## Запуск

```sh
npm install
npm run dev
```

Пересборка Tailwind в режиме наблюдения:

```sh
npx tailwindcss -i ./src/style.css -o ./dist/output.css --watch
```
